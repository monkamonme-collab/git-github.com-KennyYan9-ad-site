## Internal Linking Architecture

### Link Types

**1. Pillar Links (Level 1)**
- 從工具頁連結至各 category pillar articles
- 從首頁連結至所有 pillar articles

**2. Cluster Links (Level 2)**
- Pillar → Supporting Articles
- Supporting Articles → 相關 Supporting Articles
- 所有文章 → 相關工具頁

**3. Navigation Links (Level 3)**
- Header nav → Blog index
- Blog index → Category pages
- Category pages → 所有旗下文章

### Link Frequency Rules
- 每篇文章至少 3 個內部連結
- 連結至相同 category 的其他文章 ≥ 2 個
- 連結至相關工具頁 ≥ 1 個
- 連結至相關 pillar article ≥ 1 個

## EEAT 加強策略

**Experience (經驗)**
- 引用真實案例與飼主故事
- 納入獸醫師建議與專業觀點

**Expertise (專業)**
- 所有文章由具備寵物知識的作者撰寫
- 使用科學數據與獸醫學術來源
- 建立作者 bio 頁面

**Authoritativeness (權威性)**
- 內部連結建立主題權威
- 引用獸醫組織資料（AVMA、AAHA）
- 建立引用來源清單

**Trustworthiness (信任度)**
- 完整的免责声明
- 隱私權政策
- 聯絡方式與作者資訊
- 準確的發布日期
- 定期更新內容
